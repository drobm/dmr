EXERCISE MEDIA — drop files here
================================

Filenames must match exactly. The full list of all 56 expected
names is in media-filenames.txt, next to this file.

  photo (thumbnail):  <slug>.jpg
  looping demo clip:  <slug>.mp4

  e.g.  "Chin Tucks"  ->  chin-tucks.jpg  /  chin-tucks.mp4

You do NOT need to add all of them, and you do NOT need to touch
any code. Add files whenever you film them:

  - Photo present  -> shows as the exercise thumbnail
  - Photo missing  -> falls back to the gold category icon
  - Video present  -> plays muted and looping under the exercise
  - Video missing  -> nothing renders, no error

VIDEO TIPS
  Keep clips short (5-10s) and compressed — most visitors are on
  phones using cell data. Under ~2MB per clip is a good target.
  They autoplay muted, so they should read clearly without sound.
